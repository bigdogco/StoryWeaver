# In-session canon editor

Implemented the approved character, location, fact and item editing forms, opened
from Edit beside Back in the world panel. Each uses a detached draft with Save/Cancel,
searchable reference selection, explicit/common lore distinction and read-only pack
sheets. Changes affect the running playthrough without changing pack content, the
turn number or historical narration.

Core owns typed correction requests, target identity and cross-entity effects.
Targets include kind, dictionary key and permanent ID, avoiding ambiguous bare-ID
edits in malformed canon. Capture and save use the session guard; missing or stale
targets are refused before mutation. A complete correction writes canon once and
reports integrity findings afterwards. Unresolved references and unrelated fields
are preserved unless explicitly changed.

The desktop retains story drafts and narration position, refreshes details and links,
confirms discarding unsaved form changes, and blocks conflicting operations while
the editor is open. Save failure retains copyable draft text and requires reopening;
closing the form does not promise a rollback.

Validation: Release solution build passed with zero warnings/errors and whitespace
checks passed. The player reported manual testing looked good on 2026-09-09 and
authorized commit and push. No automated tests or agent-run model calls were made.
No new projects, dependencies or save-format changes.
